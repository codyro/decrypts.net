### 通行密钥注册

**允许通行密钥注册**开关（依赖**允许用户注册**）允许新用户仅使用通行密钥创建账户——无需邮箱和密码。开启后，登录/注册页的注册标签会将“使用通行密钥创建账户”作为突出显示的首选项。

- 账户使用服务器生成的 `pk-<随机>@passkey.invalid` 伪邮箱（保留的 `.invalid` 顶级域永远无法收信或匹配真实登录），密码为任何密码登录都无法匹配的占位值，通行密钥是唯一的登录方式。
- 如果丢失该账户的所有通行密钥将无法恢复；删除此类账户的最后一个通行密钥会被拒绝。
- 密码注册、验证码、密码登录与 OAuth2 登录均拒绝以 `.invalid` 结尾的邮箱。
- 设置了 `USER_DEFAULT_ROLE` 时，通行密钥注册会与其他注册路径一样分配默认角色。

## 禁用用户系统

在 Worker 中设置 `DISABLE_USER_SYSTEM = true` 可关闭整个用户系统：所有 `/user_api/*` 接口统一返回 403，已有用户管理员令牌不再用于后台鉴权，前端隐藏用户中心、用户管理及用户设置等用户界面。默认不配置时保持原有行为。

匿名邮箱和管理员密码登录仍可使用；请不要同时开启 `DISABLE_ANONYMOUS_USER_CREATE_EMAIL`，否则将无法自助创建邮箱。关闭用户系统不会删除已有用户或邮箱数据。
