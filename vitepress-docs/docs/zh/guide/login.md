# 登录入口与凭据

前端的三个入口对应不同对象，使用的凭据也不同：

| 入口 | 用途 | 登录凭据 |
|------|------|----------|
| `/`（或 `/:lang/`） | 打开单个邮箱，查看收件箱、发件箱和邮箱设置 | 邮箱会话 Token（Address JWT）；启用 `ENABLE_ADDRESS_PASSWORD` 后也可使用邮箱密码；再同时启用 `ADDRESS_PASSWORD_LOGIN_ONLY` 后，登录页仅提供邮箱密码登录 |
| `/user`（或 `/:lang/user`） | 登录用户中心，管理一个用户账号下绑定的多个邮箱 | 未启用 `DISABLE_USER_SYSTEM` 时可用；使用用户账号邮箱与密码、Passkey 或已配置的 OAuth2 |
| `/admin`（或 `/:lang/admin`） | 进入管理后台 | `ADMIN_PASSWORDS`；未启用 `DISABLE_USER_SYSTEM` 时，也可使用具有 `ADMIN_USER_ROLE` 的用户账号 |

用户账号的登录邮箱不会自动成为收发邮件的邮箱地址。登录用户中心后，可在“收件箱”页签查看邮件；如需直接打开单个邮箱，可从邮箱列表选择“进入邮箱”。只登录某个邮箱也不会自动登录用户中心。

## 仅通行密钥账户

部署者在 管理后台 → 用户设置 中开启**允许通行密钥注册**后，注册页签会提供“使用通行密钥创建账户”：无需邮箱和密码，仅凭可发现通行密钥即可注册并登录新账户（`POST /user_api/passkey/signup_request` + `signup_response`）。

- 账户没有可用的邮箱/密码；用户中心与管理后台将其标注为“通行密钥账户”（内部使用 `pk-<随机>@passkey.invalid` 伪邮箱，密码登录、验证码与 OAuth2 均拒绝任何 `.invalid` 邮箱）。
- 丢失所有通行密钥后账户无法恢复——界面会提示用户添加第二个通行密钥，且拒绝删除最后一个通行密钥。管理员仍可为该账户重置密码以恢复访问。

## 注销账户

部署者启用 `ENABLE_USER_BURN_ACCOUNT` 后，用户中心设置会显示“注销账户”危险操作区：输入确认短语并使用账户密码或通行密钥重新验证身份后，账户及其绑定的所有邮箱（含全部邮件、通行密钥和密钥备份）将被永久删除，浏览器也会移除这些邮箱在本地的密钥和已保存的登录信息，且无法撤销。接口见 [注销账户](./feature/mail-api.md#burn-account)。
